# Netech Cabling Website

Marketing site for Netech Cabling, a white-label telecommunications infrastructure
contractor. Plain static HTML/CSS/JS — no build step or dependencies required.

## Running locally

Open `index.html` directly in a browser, or serve the folder with any static
file server, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

| File | Purpose |
| --- | --- |
| `index.html` | Home page |
| `about.html` | Company overview |
| `capabilities.html` | Services offered |
| `why-netech.html` | Value proposition |
| `verticals.html` | Industries served |
| `case-studies.html` | Past project highlights |
| `safety-compliance.html` | Safety and compliance information |
| `careers.html` | Job openings |
| `faq.html` | Frequently asked questions |
| `contact.html` | Contact form and details |
| `styles.css` | Site-wide styles |
| `script.js` | Nav toggle and FAQ accordion behavior |
| `assets/` | Images used across the site |
